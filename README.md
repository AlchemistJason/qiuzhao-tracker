# 2027秋招内推 · 投递跟踪器

> 一键管理 2027 届秋招/提前批内推信息，跟踪投递状态，跨设备同步。

## 在线访问

**https://alchemistjason.github.io/qiuzhao-tracker/**

## 功能

- 🏢 38+ 家企业秋招/提前批内推信息（内推码一键复制、直达投递链接）
- 📊 投递状态跟踪：未投递 → 已投递 → 笔试中 → 面试中 → Offer / 已拒绝
- ⭐ 收藏 + 📝 个人备注 + 🎯 投递进度仪表盘
- ⏰ 截止日期倒计时（≤3天红色预警）
- 🔍 搜索（公司/岗位/地点/内推码）、按批次与行业筛选、排序
- 📊 表格 / 🗂️ 卡片 双视图
- 📱 跨设备二维码同步（电脑 ↔ 手机）
- 💾 数据自动备份 + 自动迁移，版本更新不丢状态

## 数据与状态说明

| 层级 | 文件 | 说明 |
|------|------|------|
| 数据层 | `data.js` | 公司列表（维护方更新，更新不碰逻辑） |
| 逻辑层 | `index.html` | 页面功能（功能更新不碰数据） |
| 状态层 | 浏览器 localStorage | 你的投递状态/收藏/备注，按浏览器隔离，互不影响 |

**状态安全机制：**
- 公司用稳定 ID 存储，公司改名/新增/删除不影响已保存状态
- 旧版本数据自动迁移（无需手动操作）
- 每次修改自动保留最近 5 份快照，数据异常自动回滚
- 可用 💾 导出备份 / 📥 导入恢复

## 跨设备同步（手机 ↔ 电脑）

1. 电脑端点击右上角 **📱** 按钮 → 「导出状态」，显示二维码
2. 手机打开本页面 → 点 **📱** → 「扫描/粘贴导入」→ 扫电脑二维码
3. 反向同步同理：手机端导出，电脑端扫/粘贴

> 没有摄像头也可用：复制/粘贴文本同步码。

## 维护

数据更新由维护方自动完成（修改 `data.js` 并发布），用户无需任何操作，已保存的状态不会丢失。
